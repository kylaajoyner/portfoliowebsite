# Kyla Joyner Portfolio

Plain HTML, CSS and JavaScript. No build step.

- `index.html` is the Work page (home), plus `about.html` and `rodeo.html`
- `css/style.css` holds the shared styles
- `js/main.js` is where animations will go
- `assets/` holds fonts and images

To preview locally, open `index.html` in a browser, or use the VS Code Live Server extension.
